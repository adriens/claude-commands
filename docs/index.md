# Bibliothèque de Skills

Bienvenue dans cette collection de commandes personnalisées pour **Claude Code**.

Ce catalogue regroupe des outils spécialisés pour étendre les capacités de votre assistant. Explorez les différentes catégories dans le menu de navigation pour trouver les outils adaptés à vos besoins.

## 🤝 Comment contribuer ?

Les contributions sont les bienvenues ! Si vous avez créé un skill utile, n'hésitez pas à **ouvrir une Pull Request** pour l'ajouter à la collection.

1. **Forkez** le projet sur GitHub.
2. **Créez** votre dossier dans `docs/skills/`.
3. **Ajoutez** votre fichier `index.md` avec le Front Matter approprié.
4. **Proposez** votre modification via une PR.
